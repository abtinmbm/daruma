# Chassis

The chassis is two to three 1/8" (3.175 mm) acrylic plates joined by M3 brass standoffs, with the motors on L-brackets under the bottom plate. The plates are written as code so hole positions come straight from the part dimensions, then exported to DXF for laser cutting.

Slots and tabs are sized to the measured sheet thickness, not a nominal 3 mm. Exports go to `cad/out/` (regenerated, not tracked).
